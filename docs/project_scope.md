# Project Scope

Project title:
Design and Verification of a Reconfigurable LFSR Based RTL Architecture for Caesar Cipher Encryption and Decryption

Scope completed:
RTL design, functional verification, waveform generation, Yosys synthesis, Sky130 HD technology mapping, static timing analysis with OpenSTA, and RTL optimization.

The project stops at RTL-to-STA analysis. Physical design stages such as OpenLane, OpenROAD, placement, routing, and GDSII were intentionally excluded from the chosen scope.
